## 🛠️ Project Overview
This application is a specialized Generative AI tool built using **Amazon PartyRock** (an Amazon Bedrock playground). It is designed to assist Cloud Engineers in quickly generating technical documentation and automation scripts, specifically focusing on AWS infrastructure deployment.

### 🧪 How it Works
The app utilizes advanced Foundation Models to process two specific user inputs:
1. **AWS Service:** The target cloud service (e.g., EC2, S3, RDS, Lambda).
2. **Task Description:** The specific goal or configuration (e.g., "Install Nginx," "Configure S3 Static Hosting").

### 📦 Key Features
* **Automated Technical Guides:** Generates comprehensive, step-by-step instructions including prerequisites and security best practices.
* **Infrastructure as Code (Bash):** Produces production-ready Bash scripts (User Data) that can be directly used during EC2 instance launches.
* **Consistency & Efficiency:** Delivers structured outputs that are more reliable and repeatable than standard, manual chatbot prompting.
