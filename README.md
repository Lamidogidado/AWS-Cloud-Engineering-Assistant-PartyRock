## 🚀 Project Overview
This application is a specialized Generative AI tool built using **Amazon PartyRock** (an Amazon Bedrock playground). It is designed to assist Cloud Engineers in quickly generating technical documentation and automation scripts.

### 🛠️ How it Works
The app utilizes large language models (LLMs) to process two specific inputs:
1. **AWS Service:** The target cloud service (e.g., EC2, S3, RDS).
2. **Task Description:** The specific configuration or installation goal.

### 📦 Features
* **Automated Technical Guides:** Provides step-by-step instructions with best practices.
* **Infrastructure as Code (Bash):** Generates ready-to-use User Data scripts for automated instance configuration.
* **Consistency:** Delivers structured outputs that are more reliable than standard chatbot prompts.
